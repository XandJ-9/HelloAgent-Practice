## 写作原则

- 先用一句话解释，再展开细节。
- 区分课程原文、自己的理解和仍未确认的问题。
- 至少链接一个相关概念、实验或自测题。
- 内容能够独立解释并经过实践后，将 `status` 更新为 `understood`。
